# Security & Responsible Use

`mcpscan` is a defensive tool for auditing MCP servers. It is **read-only**: it lists
tool/resource/prompt definitions and never invokes a tool.

## Acceptable use
- Auditing MCP servers you own or are explicitly authorized to assess.
- Vetting third-party MCP servers before connecting an agent to them.
- Security research and education.

## Reporting a vulnerability
Found an issue in mcpscan itself? Please open a private GitHub Security Advisory
rather than a public issue.
